# AI-Based Landslide Detection Using Mask R-CNN and SegFormer

This project focuses on AI-based landslide detection and segmentation using satellite imagery, implementing and comparing two deep learning architectures: **Mask R-CNN** and **SegFormer-B4**. The models are used to identify landslide-affected regions and generate segmentation masks from satellite data. The project explores different input modalities, including Sentinel-1 SAR, Sentinel-2 optical imagery, and terrain-related information, to investigate their applicability to landslide mapping. Model performance is evaluated using metrics such as precision, recall, F1-score, Dice score, and Intersection over Union (IoU).

**Collaboration:** Wadia Institute of Himalayan Geology (WIHG), Dehradun.
